# Content

`index.json` lists every URL of the original site with navigational metadata only
(path, type, title, meta description, tags, publish date). It is generated by the
research tooling from the sitemap and contains no article bodies.

Templates look for owner-supplied body HTML at:

- `content/blog/<slug>.html` — blog posts (`/blog/<slug>`; nested slugs join with `--`)
- `content/case-studies/<slug>.html` — case studies (`/case-studies/<slug>` or `work--<slug>`)
- `content/resources/<slug>.html`, `content/jobs/<slug>.html`
- `content/pages/<slug>.html` — rich-text pages such as `privacy-policy`, `terms-and-conditions`

Drop the HTML exported from the CMS (HubSpot "Export content") into these folders and
rebuild; routes without a body file render a placeholder body so the template is still visible.
