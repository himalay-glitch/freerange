- `.module.quiz-slider > .slides` (overflow hidden) with absolutely positioned slides that cross-fade (`opacity .5s`) and translate (Flickity); implement as a React slide index with the same classes (`.slide.main-container`, `.slide.questions-slider#slide-N`, `.is-selected`).

- **Question slides** (`.slide.questions-slider`, 1440×1000, background image cover positioned 100% 100% — placeholder `/placeholders/card-N.svg` per question; the illustration sits in the right half): a 12px blue progress bar fixed at the top-left (`.progress-bar { position:fixed; top:0; left:0; height:12px; background:#308bf5; border-radius:0 40px 40px 0; width: (index/8)*100vw }` — 180px wide on question 1), a 2px #308bf5 frame around the viewport (visible in the screenshot), `.question-container { position:absolute; top:50px; left:90px; width:671.9px; height:813px; padding-bottom:77.5px; display:flex; flex-direction:column; overflow:auto }` → `.que-header { display:flex; align-items:center; gap:80px; height:100px }` with `.question-number > p` (orange Colfax numeral ≈80px/80px 700 #ff4e00) + `.question-label` (22px/26px 700 #ff4e00) → `.inner-container > .answers-container` with six `button.answers-radio` (full width 672, white background, `border:1px solid #cfe3f7`, `border-radius:6px`, padding 18px 20px 18px 56px, text 18px/22px 400 #4a4a4a left-aligned, 24px radio circle (2px #308bf5 outline) at left 20px, margin-bottom 20px; selected → filled blue circle + `border-color:#308bf5`) → `.prev-next-buttons { position:fixed; bottom:77px; left:90px; width:671.9px; display:flex; justify-content:space-between }` with two `button.cta-button.flickity-button` 38×38 `background:#ff4e00; border-radius:8px; padding:5px; color:#fff` (white chevron icons 16px; `.next` has `opacity:.6` until an answer is chosen). - **Flow:** choose an answer → next enabled; next/prev move between questions; after the 12th question compute the archetype with the most selected answers and `router.push('/<archetype>')`. Data: 12 placeholder questions each with 6 answers mapped to the six archetypes (creator, leader, entertainer, guardian, innovator, sage).
- Mobile (≤767): illustration becomes a top image block, question container static full width (padding 20px), buttons static below the answers, progress bar full width 8px.
