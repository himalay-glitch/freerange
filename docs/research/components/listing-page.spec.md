Behaviour: checking filters narrows the cards to entries having ALL selected tags (client-side over the provided list); search filters by title substring; toggle collapses the sidebar (`.show-filters` removed) and the cards area widens; "Clear Filters" resets. Keep URL `?tags=` in sync with `useSearchParams` for deep links from card tag links.

## Props
`<ListingPage variant="blog"|"case-studies"|"resources" headline?: ReactNode filterGroups={{ title, options: { label, slug }[] }[]} items={(PostCard|CaseStudyCard & { tags: string[] })[]} />` — `items` is the full collection (the page builds it from `content/index.json` titles + placeholder images), the component paginates. Provide `listing-demo.ts` with filter groups per variant: blog → Services (Storytelling, Design, Workshops, Product Innovation); case-studies → Services + Issues & Causes (Climate & Sustainability, Humanitarian, Education, Health, Equity) + Industries (Nonprofits, Ventures, Education, Government); resources → Services + Category (Downloads, Blog, Podcast, R&D Lab).

## Responsive (port listing.css exactly)
≤999: cards stack full width (card-list.css); ≤767: filter bar stacks (search gets border-top instead of border-left), sidebar full width above the cards (`flex:1 0 auto; max-width:100%; margin-bottom:20px`), wrapper `flex-direction:column; margin-top:20px`; headline 28px/40px.
