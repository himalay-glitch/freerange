## Overview
- **Target files:** `src/components/home/Hero.tsx` (client), `src/components/home/shapeshifter.ts` (canvas morph engine), `src/components/home/hero-shapes.ts` (demo polygon sets), `src/styles/hero.css`
- **Screenshot:** `docs/design-references/home-01-hero.png` (1440), mobile in `home-mobile-390-full.png` (top)
- **Source of truth:** `docs/research/html/home-hero.html`, `docs/research/css/hero.css` (authoritative), computed tree `docs/research/raw/home-hero.json`, behavior notes in `docs/research/BEHAVIORS.md` (Hero)
- **Interaction model:** click-driven (cycle shapes) + hover (tooltip/polygon highlight) + mouse-move parallax + timed typewriter

## Content policy
The live hero morphs between six proprietary low-poly bird illustrations. Do NOT reproduce them. Implement the engine generically over `HeroShape[]` (`{ name, text, viewBox:[717,484.2], polygons:[{ points:[[x,y],…], fill:'#hex' }] }`) and ship six ORIGINAL procedurally generated low-poly shapes (e.g. triangulated silhouettes of simple geometric creatures/objects built from ~150–250 triangles each with a warm palette of 8–12 colours). Names/captions: use generic placeholder names ("Shape One"…"Shape Six") and short placeholder captions (2 sentences each). The real data can later be dropped into `hero-shapes.ts` without touching the component.

## Behaviors (port from theme JS, described in BEHAVIORS.md)
1. **Shapeshifter engine** (`shapeshifter.ts`): class `Shapeshifter(canvas, polygons, opts)` with `opts = { transformSpeed:{x,y}, hideSpeed:{x,y}, opacitySpeed, colorSpeed, scale, center, strokeOnly, strokeOpacity, hideInitialAnimation }`. State per polygon: current points, target points, current rgb, target rgb, opacity. `loop()` each rAF: for every polygon lerp points → target by `transformSpeed`, colour by `colorSpeed`, opacity by `opacityspeed`; polygons beyond the target count shrink to their centroid (`hideSpeed`) and fade out; clear + draw (fill or stroke). `transform(nextPolygons)` sets new targets (map by index; missing targets = hide). Scale/centre the 717×484.2 shape within the canvas. FG: `{transformSpeed:.07, hideSpeed:.07, opacitySpeed:.03, colorSpeed:.03, scale:.8, center:true}`; BG: `{transformSpeed:.04, hideSpeed:.04, opacitySpeed:.03, colorSpeed:.03, scale:.9, center:true, strokeOnly:true, strokeOpacity:.4}`.
2. **Click** anywhere on the visible hidden-layer polygons → `index = (index+1) % 6`; both engines `transform(shapes[index])`; set `hero-animation-current-index`; clear caption and after 1500ms type the new caption (4ms per character; on <768 set instantly). Touch swipe right → back two.
3. **Hover** polygon → tooltip visible & follows mouse (`mousemove` on window; `left = clientX - containerLeft + 20; top = clientY - containerTop + 20`).
4. **Parallax** on mouse move over the hero: translate `.hidden-layer`/`.layer-fg` by `depth .1` and `.layer-bg` by `depth .7` of the pointer offset from centre (friction .075 → ease with lerp each frame). Simple implementation: `translate3d(dx*depth, dy*depth, 0)` where `dx = (mouseX - w/2) * 0.1` style factor matching parallax.js (≈ ±40px for bg, ±6px for fg at viewport edges).
5. On mount: after 1500ms add `.shown` to `.typewriter-container` and type caption 0. Start rAF loop; pause it when the hero is out of the viewport (IntersectionObserver).
